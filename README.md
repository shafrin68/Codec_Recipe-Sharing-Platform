# Codec_Recipe-Sharing-Platform
A Full Stack Recipe Sharing Platform built using HTML, CSS, JavaScript, Node.js, Express.js and MongoDB. Users can add, search, filter and delete recipes.

# Recipe Sharing Platform

A search-focused recipe sharing web application.

## Technologies Used

- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB

## Features

- Add and share recipes
- Search recipes by name or ingredients
- Filter recipes by category
- Delete recipes
- Validate recipe data
- RESTful API integration

## Backend Setup

Install Node.js and MongoDB first.

Run these commands inside the backend folder:

npm install
npm start

The backend runs at http://localhost:5000.

## Frontend Setup

Create a React project using Vite.

Copy index.html, src.jsx and style.css
into the appropriate frontend files.

Install React and React DOM, then run:

npm run dev

Make sure MongoDB is running before using the application.
